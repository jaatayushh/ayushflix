## 🌟 What is Ayushflix?

**Ayushflix** is a modern media streaming client built from the ground up for film and television enthusiasts. Unlike typical media applications that require hunting down third-party repository URLs, installing extensions, and constantly dealing with broken links, **Ayushflix comes 100% pre-configured out-of-the-box**.

Available across **Android Smartphones**, **Tablets**, **Android TV / Google TV**, and as a standalone native **Windows 10 & 11 Desktop Application** (`.exe`).

## ✨ Features

- **⚡ Instant 1080p FHD Playback**: Stream in crisp 1080p Full HD, 720p HD, and auto-adaptive resolutions.
- **🎧 Intelligent Hindi Dub Auto-Selector**: Movies with multi-language audio (Hindi, English, Tamil, Telugu) automatically start in **Hindi** without needing to manually toggle audio tracks.
- **🛡️ Authentic Stream Extraction**: Automatically decodes signed CloudFront policies and bypasses decoy update prompts and dummy video traps.
- **🖥️ Standalone Windows Desktop App**: Ultra-fast single-file `.exe` utilizing hardware-accelerated Microsoft Edge WebView2 with bundled Dash.js & Hls.js engines.
- **📺 Android TV & Google TV Optimized**: Full Leanback 10-foot UI with remote D-pad navigation, continue watching row, and clock.
- **💬 Subtitles On Demand**: Automatic multi-language subtitle fetching with customizable styling, sizing, and delay synchronization.
- **⬇️ Offline Download Engine**: Built-in multi-threaded downloader with resume capability for on-the-go viewing.
- **🔒 Private & Open**: No tracking, no telemetry, and no registration required.

## 📲 Installation Guide

### 📱 Android Smartphone / Tablet
1. Download [**Ayushflix-v1.0.4.apk**](https://github.com/jaatayushh/ayushflix/releases/download/v1.0.4/Ayushflix-v1.0.4.apk).
2. Tap the downloaded `.apk` file.
3. If prompted, toggle **Allow from this source** in your device settings.
4. Tap **Install** and launch **Ayushflix**!

### 📺 Android TV, Google TV & Amazon FireStick
1. **Method A (Send Files to TV)**:
   - Install *Send Files to TV* on both your phone/PC and your Android TV.
   - Send `Ayushflix-v1.0.4.apk` to your TV and install using a file manager (e.g., *File Commander*).
2. **Method B (USB Drive)**:
   - Copy `Ayushflix-v1.0.4.apk` onto a FAT32/NTFS formatted USB flash drive.
   - Plug into your TV, open a file manager, and select the APK to install.
3. **Method C (Downloader App)**:
   - Open the *Downloader* app on FireStick / Android TV.
   - Enter the direct release URL: `https://github.com/jaatayushh/ayushflix/releases/download/v1.0.4/Ayushflix-v1.0.4.apk` to download and install.

### 💻 Windows 10 / 11
1. Download [**Ayushflix-Windows-v1.0.4.exe**](https://github.com/jaatayushh/ayushflix/releases/download/v1.0.4/Ayushflix-Windows-v1.0.4.exe).
2. Move it to any folder of your choice (e.g. `C:\Users\<Name>\Desktop`).
3. Double-click to launch! *(Edge WebView2 runtime is pre-installed on Windows 10 & 11).*

## 🛠️ Building From Source

### 1. Building the Android APK
```bash
# Clone the repository
git clone https://github.com/jaatayushh/ayushflix.git
cd ayushflix

# Compile the production signed release APK
./gradlew assembleStableRelease
```
The compiled APK will be located at:
`app/build/outputs/apk/stable/release/app-stable-release.apk`

### 2. Building the Windows Standalone Executable
```bash
# Install desktop dependencies
pip install pywebview requests pycryptodome pyinstaller

# Compile standalone single-file .exe
pyinstaller --noconfirm --onedir --windowed \
  --icon="desktop/icon.ico" \
  --name="Ayushflix" \
  --add-data="desktop/ui;ui" \
  --collect-all="webview" \
  desktop/app.py
```
